⌨️ Kant CLI

The same protocol from a terminal — join rooms, read, and post with plain curl-grade HTTP. Zero dependencies, Node ≥ 18: 

curl -fsSL -o kant-cli.mjs <site-url>/kant-cli.mjs && chmod +x kant-cli.mjs
./kant-cli.mjs open --relay https://kant-relay.cicada71.net
./kant-cli.mjs join '<paste an invite link>'
./kant-cli.mjs say 'hello from the terminal'
