# Deployment Instructions for Kant Pastebin

## Systemd Service

1. Copy the systemd service file to the system directory:
   ```bash
   sudo cp kant-pastebin.service /etc/systemd/system/
   ```

2. Reload systemd daemon:
   ```bash
   sudo systemctl daemon-reload
   ```

3. Enable the service to start on boot:
   ```bash
   sudo systemctl enable kant-pastebin.service
   ```

4. Start the service:
   ```bash
   sudo systemctl start kant-pastebin.service
   ```

5. Check the status:
   ```bash
   sudo systemctl status kant-pastebin.service
   ```

## Nginx Configuration

1. Copy the nginx configuration snippet to the sites-available directory:
   ```bash
   sudo cp kant-pastebin.nginx /etc/nginx/sites-available/kant-pastebin
   ```

2. Create a symbolic link in sites-enabled:
   ```bash
   sudo ln -s /etc/nginx/sites-available/kant-pastebin /etc/nginx/sites-enabled/
   ```

3. Test nginx configuration:
   ```bash
   sudo nginx -t
   ```

4. Reload nginx:
   ```bash
   sudo systemctl reload nginx
   ```

## Cloudflare Worker Deployment (via SOPS)

The `deploy-cloudflare-worker.sh` script uses SOPS to manage Cloudflare credentials.

### Prerequisites
- Install [sops](https://github.com/getsops/sops)
- Install [wrangler](https://developers.cloudflare.com/workers/cli-wrangler/install-update/)
- Install [nix](https://nixos.org/download.html) (for building the Rust WASM binary)

### Setup SOPS Credentials

1. Ensure you have the Cloudflare API token and account ID for the kant account.

2. Create a temporary file with the credentials:
   ```bash
   cat > /tmp/creds.yaml <<EOF
   api_token: <your_cloudflare_api_token>
   account_id: <your_cloudflare_account_id>
   EOF
   ```

3. Encrypt the credentials using SOPS and the project's PGP keys:
   ```bash
   sops --encrypt --pgp A76A0CF9079EC60D --pgp 445EB57704130B8D -o .sops/credentials.sops.yaml /tmp/creds.yaml
   ```

   Note: The PGP keys are defined in `.sops.yaml`.

4. Remove the temporary file:
   ```bash
   rm /tmp/creds.yaml
   ```

### Deploy the Workers

Run the deploy script:
```bash
./deploy-cloudflare-worker.sh deploy
```

This will deploy two workers:
- `kant-zk-relay-wasm` (Lean WASM relay)
- `kant-zk-pastebin-wasm` (Rust WASM pastebin tool)

### Verify Deployment

After deployment, run:
```bash
./deploy-cloudflare-worker.sh verify
```

To check the health of the deployed workers.

### View Status

To see the deployment status:
```bash
./deploy-cloudflare-worker.sh status
```

## Notes

- The systemd service expects the binary at `/nix/store/yj5xsj7yhp14z5hlmygkha1fa4zri4bi-kant-pastebin-0.1.0/bin/kant-pastebin`.
  This path is generated by Nix. You may need to build the project with `nix build` first.

- The nginx configuration assumes the service is running on `127.0.0.1:8090` and the base path is `/pastebin`.

- The SOPS configuration uses PGP keys `A76A0CF9079EC60D` and `445EB57704130B8D` for encryption.

- If the Cloudflare account is over quota, you may need to upgrade or delete unused workers.
