Diagnostics

Everything the network does is written down: every probe, every request, every refusal, every error. Nothing is swallowed.

Holding two codes that will not connect? The diagnostics page has What is this code?: paste both and it says what each one is. A share card or a page link names a page, never a room — only a kzinvite code can join two clients.
