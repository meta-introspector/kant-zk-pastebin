Carry it by hand

No server, no relay, no network between you: two people with any chat window — Signal, SMS, a shared document, a photograph of a screen — copy one code each way and end up holding the same conversation. The four steps, and the proof that none of them needs anything running anywhere, are RequestProject/Kant/Handoff.lean; that the codes carry everything and lose nothing is RequestProject/Kant/Uucp.lean.

    Carry a block by hand

    The same thing for a post: a block copied out of one device's store and pasted here lands under exactly the address it left with, because the store is addressed by content and not by trust (Kant.Handoff.carry_resolves). A run shared from the app's Post the log to the store button travels this way too.

    The rules on this page are proved, not tested: Kant.Handoff.run_agree (four copy-pastes and both sides show the same conversation), Kant.Handoff.script_serverless (no step needs a server), Kant.Uucp.readThread_perm (the numbered messages may arrive in any order) and Kant.ShareLog.readChatParts_chatParts (a run survives the same trip).
