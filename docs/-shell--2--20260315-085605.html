### DASL CBOR Envelopes for All IPFS Blocks
- `dasl_envelope()` in `src/lib.rs` creates JSON envelope with: `prefix` (0xDA51), `dasl_type` (3), `cid`, `dasl` (Monster symmetry address), `orbifold` [l,m,n] coords mod (71,59,47), `bott` index, `mime`, `encoding`, `size`, `source` (original text), `created` (ISO timestamp via `js_sys::Date`)
- Helper functions: `dasl_address()` (0xda51 + 48-bit hash), `orbifold_coords()` (mod Monster primes)
- `ipfs_put_dasl(data, mime, encoding, source)` stores block + envelope + auto-creates RDFa triple linking `source_cid --erdfa:{encoding}--> block_cid`
- `ipfs_meta(cid)` retrieves envelope JSON
- All 7 JS callers updated with encoding labels: `morse`, `bbs-dtmf`, `numbers-station`, `cassette-kcs`, `stego-lsb`

### WAV Generation for All Encodings
