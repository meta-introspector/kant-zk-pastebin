- `src/main.rs` — Routes + plugin registry initialization

### File Upload Support
- `POST /upload` — Multipart file upload (images, HTML, JSON, SVG)
- `GET /file/{id}` — Raw file serving with correct MIME type
- `.meta` sidecar files for uploaded binary files
- Image files render inline on view page
- Form has file picker that switches between text paste and file upload

### Thread/Reply System
- `POST /paste` accepts `reply_to` field
- `GET /thread/{id}` — Returns parent + all replies sorted chronologically
- `Reply-To:` stored in paste file headers
- Reply button on view page

### Auto-fill on POST
- Server-side auto-tag, auto-describe, HTML title extraction on paste creation
- Title auto-generated from HTML `<title>` or content description
- Keywords auto-populated from content analysis

### DASL/CBOR Integration
- File headers now include `DASL:` field alongside `IPFS:`
- `dasl_cid()` computes 64-bit Monster symmetry address
- `wrap_dasl_cbor()` creates CBOR envelope with orbifold coords, Bott index, content, CIDs

### Plugin System
- `Plugin` trait: `name()`, `version()`, `description()`, `execute(PluginInput) -> PluginResult`
- `PluginRegistry` with register/get/list/execute
- `PluginInput` struct: id, content bytes, mime, url, extra params
- `GET /plugins` — List available plugins
- `POST /plugin/{name}/{id}` — Run plugin on a paste
- Screenshot plugin registered (headless chromium)

### ContentStore Trait (src/ipfs.rs)
```rust
pub trait ContentStore: Send + Sync {
    fn name(&self) -> &str;
    fn add(&self, data: &[u8]) -> Option<String>;
}
```
Backends: `RustStore` (pure Rust UnixFS CID), `DaslCborStore` (CBOR envelope), `IpfsCliStore` (shells out)

### IPFS CID Computation (src/ipfs.rs)
Pure Rust UnixFS encoding: content → UnixFS protobuf (Type=File) → dag-pb Node → SHA256 → CIDv1 base32. Functions: `encode_unixfs()`, `encode_dagpb()`, `encode_varint()`, `ipfs_cid_bytes()`.

### DASL Address Format (src/dasl.rs)
64-bit: `[0xDA51:16][type:4][data:44]`. Types 0-5 defined. `orbifold_coords()` maps to Z/71 × Z/59 × Z/47. `harmonic_slide()` bridges 10-fold ↔ 8-fold. Constants: `MONSTER_PRIMES`, `MONSTER_EXPONENTS`, `BOTT_COORDS`, `TENFOLD_COORDS`, `HECKE_PRIMES`.

### DaslObject CBOR Envelope (src/ipfs.rs)
```rust
pub struct DaslObject {
    pub prefix: u64,        // 0xDA51
    pub dasl_type: u8,      // 3 = nested CID
    pub orbifold: (u64, u64, u64),
    pub bott: u8,
    pub data: Vec<u8>,      // content bytes
    pub cid: String,        // IPFS CID
    pub dasl: String,       // DASL address
}
```
