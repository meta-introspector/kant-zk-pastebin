# Roadmap toward ZOS Experimental Alpha

## Completed experimental milestones

- Resource-constrained Wasmi runtime.
- Verified immutable artifact representation.
- Historical Rust-Lean authority integration.
- Private execution boundary.
- Non-test external Rust consumer.
- Canonical request and replay model reproduction.
- Real offline Kubo-to-Rust denial integration.
- Expanded authenticated-request contract model.

## Next engineering milestones

1. Reconcile expanded V2 schema and trust boundaries.
2. Qualify strict canonical encoding in Rust.
3. Verify synthetic signatures using a trusted test registry.
4. Bind caller identity, artifact, certificate and policy.
5. Integrate real proof verification and applicability.
6. Establish durable authorization/effect semantics.
7. Qualify bounded inert positive execution separately.
8. Integrate experimental receipt and accounting paths.
9. Rebuild and test an independently reproducible alpha.
10. Obtain independent technical review.

Operational governance and economic rules require
separate decisions and qualification.

This roadmap is not a release commitment.
